# رسائل الأولياء — متوسطة الشهيد بدراني بوعمامة

تطبيق واحد يرسل رسالة SMS لولي التلميذ عندما يسجّل الأستاذ غيابه في **دفتر الغيابات (daftar)**.

- **دخول بحساب المدير في دفتر الغيابات** (نفس البريد وكلمة المرور). لا رمز ربط ولا رابط.
- **هاتف المؤسسة هو الذي يرسل** من شريحته: يدخل المدير في التطبيق عليه ويضغط «تشغيل الإرسال من هذا الهاتف»، فيواصل الإرسال حتى والتطبيق مغلق وبعد إعادة تشغيل الهاتف.
- **daftar لا يتغيّر**: المشروع **يقرأ فقط** من ملف «دفتر الغيابات — قاعدة البيانات» على Drive.
- الرسالة تُجهَّز **بعد نهاية الحصة بـ 10 دقائق** (مهلة تصحيح الأستاذ)، رسالة كل دقيقة ونصف، وحد أقصى 400 رسالة في اليوم.
- الحصص المتتالية مع نفس الأستاذ والقسم = رسالة واحدة. إن حُذف الغياب قبل الإرسال تُلغى رسالته.
- نفس الواجهة تعمل أيضا كصفحة ويب من الحاسوب (رابط المشروع `/exec`) للمتابعة وإدخال أرقام الأولياء.

```
gas/        مشروع Google Apps Script: الخادم (Code.gs) + الواجهة (Index.html) + appsscript.json
android/    تطبيق «رسائل الأولياء» (المصدر). الواجهة نفسها gas/Index.html تُنسخ إليه عند البناء
releases/   daftar-sms.apk  ← تطبيق «رسائل الأولياء» 2.0
```

## الخطوات

### 1. تحديث المشروع على Google (مرة واحدة، أو بعد كل تحديث)
1. افتح مشروع «رسائل الأولياء» على script.google.com.
2. الصق `gas/Code.gs` مكان Code.gs، و`gas/Index.html` مكان ملف **Index** (الاسم Index بالضبط).
3. أول مرة فقط: اختر الدالة **setup** ← ▶ تشغيل ← اسمح بالأذونات.
4. **نشر ← إدارة عمليات النشر ← ✏️ ← الإصدار: إصدار جديد ← نشر** (الرابط يبقى نفسه).
   > الرابط المدمج في التطبيق: `https://script.google.com/macros/s/AKfycbxe0mtu9Ix6v_oVhWT0skpWbkLlX_Ji3DS9XM_LxQFSAsjsLLHXAjM7VUhOY_hY-jBX-g/exec`
   > إن نشرت «نشرا جديدا» برابط آخر يجب بناء التطبيق من جديد بالرابط الجديد (`Cfg.SERVER`).

### 2. هاتف المؤسسة (الذي فيه الشريحة)
1. ثبّت `releases/daftar-sms.apk` (يُثبَّت فوق «مرسل رسائل الغيابات» القديم).
2. افتحه ← ادخل بحساب المدير.
3. تبويب **«اليوم»** ← اختر شريحة المؤسسة إن كانت شريحتان ← **«تشغيل الإرسال من هذا الهاتف»** ← «سماح» ← «السماح بالعمل دائما» (البطارية).
4. اتركه موصولا بالشاحن والإنترنت أثناء الدوام.

### 3. أرقام الأولياء (تبويب «هواتف الأولياء» — من الهاتف أو الحاسوب)
- **Excel**: ملف فيه «رقم التعريف» و«هاتف الولي» ← قراءة الملف ← حفظ.
- **يدويا**: اختر القسم ← اكتب الأرقام ← حفظ.

### 4. التجربة (تبويب «الإعدادات» ← رسالة تجريبية)
اكتب رقما ← «إرسال تجريبي» ← تصل خلال دقيقتين، وتظهر في «اليوم» كـ «أُرسلت».

## ملاحظات
- **مفتاح التوقيع** `android/sms-release.keystore` غير موجود في المستودع عمدا: احتفظ به، فبدونه لا يُثبَّت تحديث فوق التطبيق.
- البناء: `SDK_BT=… SDK_JAR=…/android-34/android.jar KEYSTORE=…/sms-release.keystore android/build_apk.sh`
- الإعدادات في أعلى `Code.gs`: `CORRECTION_MINUTES`، `GAP_SEC`، `MAX_PER_DAY`، `DEVICE_TOKEN_DAYS`.
- تغيير كلمة مرور المدير في دفتر الغيابات يُخرج التطبيق: ادخل من جديد ثم «تشغيل الإرسال».
