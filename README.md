# رسائل الأولياء (sms) — متوسطة الشهيد بدراني بوعمامة

يرسل رسالة SMS لولي التلميذ عندما يسجّل الأستاذ غيابه في **دفتر الغيابات (daftar)**.

- **daftar لا يتغيّر**: هذا المشروع **يقرأ فقط** من ملف «دفتر الغيابات — قاعدة البيانات» على Drive.
- الرسالة تُجهَّز **بعد نهاية الحصة بـ 10 دقائق** (مهلة تصحيح الأستاذ)، وتُرسل **من شريحة المؤسسة**، رسالة كل دقيقة ونصف.
- الحصص المتتالية مع نفس الأستاذ والقسم = رسالة واحدة. إن حُذف الغياب قبل الإرسال تُلغى رسالته.

```
gas/        مشروع Google Apps Script (الخادم + صفحة المدير)
  Code.gs   Index.html   appsscript.json
android/    تطبيق «مرسل رسائل الغيابات» (المصدر)
releases/   daftar-sms.apk  ← يُثبَّت على هاتف المؤسسة فقط
```

## الخطوات (مرة واحدة)

### 1. مشروع Google جديد (بنفس حساب Gmail الذي فيه دفتر الغيابات)
1. script.google.com ← **مشروع جديد** ← سمّه «رسائل الأولياء».
2. الصق `gas/Code.gs` مكان محتوى Code.gs.
3. **+** ← **HTML** ← الاسم **Index** ← الصق `gas/Index.html`.
4. ⚙️ إعدادات المشروع ← فعّل «عرض ملف appsscript.json» ← الصق `gas/appsscript.json`.
5. اختر الدالة **setup** ← **▶ تشغيل** ← اسمح بالأذونات (خيارات متقدمة ← الانتقال ← سماح).
   - تجد ملف «دفتر الغيابات — قاعدة البيانات» تلقائيا، وتنشئ ملفا جديدا «رسائل الأولياء (sms) — البيانات».
6. **نشر** ← **نشر جديد** ← تطبيق ويب ← التنفيذ باسم: **أنا** ← الوصول: **أي شخص** ← نشر ← انسخ الرابط (`/exec`).

### 2. الدخول
افتح الرابط ← ادخل **بحساب المدير في دفتر الغيابات** (نفس البريد وكلمة المرور).

### 3. هواتف الأولياء (تبويب «هواتف الأولياء»)
- **Excel**: ملف فيه عمود «رقم التعريف» وعمود «هاتف الولي» ← قراءة الملف ← حفظ.
- **يدويا**: اختر القسم ← اكتب الأرقام ← «حفظ هواتف هذا القسم».

### 4. هاتف المؤسسة (الشريحة)
1. ثبّت `releases/daftar-sms.apk` («مرسل رسائل الغيابات») — على هذا الهاتف فقط.
2. افتح رابط «رسائل الأولياء» **من متصفح نفس الهاتف** ← الإعدادات ← **«ربط هذا الهاتف»**
   (أو «نسخ رابط الربط» والصقه في التطبيق).
3. في التطبيق: «سماح» لإرسال الرسائل ← اختر الشريحة إن كانت شريحتان ← **تشغيل** ← «السماح بالعمل في الخلفية».
4. اتركه موصولا بالشاحن والإنترنت.

### 5. التفعيل والتجربة (تبويب «الإعدادات»)
1. ضع علامة على «تفعيل إرسال الرسائل للأولياء» ← حفظ.
2. **وضع التجربة**: اكتب رقما ← «إرسال تجريبي» ← تصل خلال دقيقتين.
3. تبويب «اليوم» يبيّن: اتصال الهاتف، والرسائل (في الانتظار / أُرسلت / فشلت / بدون هاتف).

## ملاحظات
- **احتفظ بمفتاح التوقيع** `android/sms-release.keystore` (غير موجود في المستودع عمدا): بدونه لا يُثبَّت تحديث فوق التطبيق.
- بناء التطبيق: `SDK_BT=… SDK_JAR=…/android-34/android.jar KEYSTORE=…/sms-release.keystore android/build_apk.sh`.
- غيابات ما قبل التفعيل لا تُرسل. الإعدادات في أعلى `Code.gs` (`CORRECTION_MINUTES`، `GAP_SEC`).
